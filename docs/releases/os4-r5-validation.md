## 已有工作区证据

现有 Phone / Pad 已完成 Core 4 / Apps 3 正常升级与冷启动、天气相同签名 APK 保数据重装后的路径恢复，以及两模块状态 WebUI 检查；root、全局 SELinux Enforcing、HWUI `skiavk` 与 60 Hz 已核验。OEM / Parrot 虚拟场景基础预览通过，未扩大为完整算法验收。详细范围见[补丁与运行证据](../os4-patches.md)。

Phone 的已审计 Vulkan 组合关闭 `VulkanQueueSubmitWithCommands` 后，实际解锁桌面 60 秒的宿主 CPU 中位为 26.7%，此前 180 秒空闲样本为 117%；采样未再出现对应解码器忙等。三轮主屏相机 → 设置切换无 ANR，正常关机约 8.2 秒自行退出。这是有限场景的前后证据，采样时长不同，不代表所有界面或长期性能；Pad 未应用该参数变更。

## 未闭环范围

- OEM / Parrot 完整 JPEG、HDR、录像及全部焦点 / 背屏路径尚未验收；预览和库加载不能替代这些功能。
- FindDevice 20.15.70 未提供 APK，未知应用更新仍需内容审计；局部跳过不表示该更新功能正常。
- Google 登录、Play Integrity、蓝牙与小米云服务未完整验证；KSU root 域仍为 permissive，全局 Enforcing 未放宽。
- 本轮实际来宾保数据升级目标为 r4 → r5；其它来源修订依赖通用兼容测试，不宣称逐个来宾路径均已验证。
